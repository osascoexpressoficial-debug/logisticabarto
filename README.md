# Proposta BARTÔ Rock & Comedy × Osasco Express

Versão final com hero personalizado da marca BARTÔ, planos de gestão logística a partir de R$ 699, diárias, taxas por distância e CTA para reunião online.

## Como subir no GitHub Pages
1. Suba todos os arquivos desta pasta no repositório.
2. Mantenha `index.html` na raiz.
3. Mantenha a pasta `assets/` junto ao HTML.
4. Ative o GitHub Pages apontando para a branch principal.

## Arquivos principais
- `index.html`
- `assets/hero-barto-fundo-personalizado.webp`
- `assets/logo-barto.png`
- PDFs e DOCX da proposta, contrato e termo de agenda.
